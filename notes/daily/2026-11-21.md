## Feature Upgrade: 1-Click Autofill Extension v2.1 (All 3 AI Bridge Architectures Built)
- **Problem:** On custom ATS forms (e.g. Atlan on Ashby ATS), standard fields filled automatically, but custom screening/essay questions (e.g., "Tell us about an AI agent you've built", "Hardest problem faced", compensation, total experience, privacy checkbox) remained empty.
- **Solution:** Built and integrated all three requested AI connection architectures into the extension and project workspace:
  1. **Method 1 (Instant Local Project Bridge API):**
     - Native background Python HTTP server running on `http://127.0.0.1:8765`.
     - Extension detects unfilled inputs/textareas, passes them via `POST /api/fill`, and injects answers into the DOM in < 1 second.
     - Powered by `tools/bridge/engine.py` (Gemini 2.0 Flash + grounded candidate facts library). Zero vision token cost.
  2. **Method 2 (Two-Way File Bridge):**
     - Extension exports unfilled questions to `documents/applications/pending_form.json` via `POST /api/export-pending`.
     - Antigravity synthesizes tailored answers into `documents/applications/ready_answers.json` (or via `python tools/bridge/synthesize.py`).
     - Extension button `📥 M2: Inject` fetches answers from `/api/ready-answers` and fills matching DOM elements.
  3. **Method 3 (1-Click Clipboard Export & Chat Injection):**
     - Extension extracts unfilled questions and copies a formatted Markdown prompt directly to candidate's clipboard.
     - Candidate pastes into Antigravity conversation; Antigravity returns a structured JSON block.
     - Extension button `📥 M3: Paste Fill` parses the JSON and injects answers directly into the active form.
- **Chrome Mixed Content & PNA Resolution:**
  - Resolved Chrome's Private Network Access / Mixed Content block on public HTTPS pages (`jobs.ashbyhq.com` -> `127.0.0.1:8765`) by adding a Background Service Worker proxy (`background.js`) in `manifest.json`.
  - Restored `service_worker: "background.js"` for Chrome Manifest V3, resolving `'background.scripts' requires manifest version of 2 or lower`. Saved `manifest.firefox.json` for Gecko.
  - Re-anchored `callBridge` and `directFetch` in `content.js`, resolving `ReferenceError: callBridge is not defined`.
  - Added Ashby combobox autocomplete helper for Location/Country selection ("India").
  - Fixed Location combobox label extraction: prevented the generic essay response from being injected into the Country/Location dropdown; added strict DOM filtering in `getUnfilledFields()` so Location is handled exclusively as an autocomplete country selection rather than an open essay.
  - Added `autofillOptionGroups()` in `content.js` & `autofill.user.js`: automatically auto-clicks Yes/No button toggle groups (live coding interview without AI, ElevenLabs product usage, full-time education, work authorization, sponsorship), notice period radio options (`Up to 4 weeks`), and dropdown selects.
